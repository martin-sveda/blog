Azure Static Web Apps je služba, které umožňuje hostování statických webových stránek v cloudu Azure.
Celý proces deploymentu lze s pomocí GitHub actions zautomatizovat, ale o tom, až příště.

## Založení účtu Azure

Na stránkách [Azure](https://azure.microsoft.com/cs-cz/free/) si založte svůj free účet Azure. I když je
účet zdarma, tak je to tuším jen na jeden rok, takže po vás bude portál při založení chtít vložení
čísla kreditní karty. Po roce bude služba normálně účtována, ale poplatky by neměly být tak vysoké, aby
vás mohly zruinovat.
